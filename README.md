# cloud-risk-register
A structured cloud risk register demonstrating cloud security fundamentals, risk scoring, mitigation strategies, and governance controls.

## Overview
This project identifies, scores, and mitigates common cloud risks in Google Cloud. It demonstrates cloud security fundamentals, governance controls, and risk management practices used in real-world cloud environments.

## Why This Matters
Cloud environments introduce unique risks such as IAM misconfigurations, public exposure, weak logging, and insecure compute defaults. This project shows how to identify and mitigate these risks using industry best practices.

## Included Files
- **risk-register.csv** — Full list of cloud risks with scoring and controls  
- **risk-scoring-model.md** — Likelihood, impact, and scoring formula  
- **mitigation-strategies.md** — Clear remediation steps for each risk  

## Scoring Model
Risk Score = Likelihood × Impact  
- High: 15–25  
- Medium: 8–14  
- Low: 1–7  

## Cloud Controls Used
- IAM  
- VPC  
- Logging  
- Storage  
- Compute
